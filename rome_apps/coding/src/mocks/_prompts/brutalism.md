## Visual style: Brutalism
- **Type:** General  ·  **Origin/Era:** 1950s Brutalist  ·  **Complexity:** Low
- **Look & feel / keywords:** Raw, unpolished, stark, high contrast, plain text, default fonts, visible borders, asymmetric, anti-design
- **Art direction:** Create a brutalist design with raw, unpolished, stark aesthetic. Use pure primary colors (red, blue, yellow), black & white, no smooth transitions (instant), sharp corners, bold large typography, visible grid lines, default system fonts, intentional 'broken' design elements.
- **Primary colors:** Primary: Red #FF0000, Blue #0000FF, Yellow #FFFF00, Black #000000, White #FFFFFF
- **Secondary colors:** Limited: Neon Green #00FF00, Hot Pink #FF00FF, minimal secondary
- **Effects & animation:** No smooth transitions (instant), sharp corners (0px), bold typography (700+), visible grid, large blocks
- **Key design values:** --border-radius: 0px, --transition-duration: 0s, --font-weight: 700-900, --colors: primary only, --border-style: visible, --grid-visible: true
- **Best suited for:** Design portfolios, artistic projects, counter-culture brands, editorial/media sites, tech blogs
- **Avoid for:** Corporate environments, conservative industries, critical accessibility, customer-facing professional
- **Theme support:** Light ✓ Full · Dark ✓ Full  ·  **Mobile:** ◐ Medium  ·  **Conversion:** ✗ Low
- **Accessibility:** ✓ WCAG AAA  ·  **Performance:** ⚡ Excellent

## Recommended typography
- **Pairing:** Brutalist Raw (Mono + Mono)
- **Heading typeface:** Space Mono
- **Body typeface:** Space Mono
- **Mood:** brutalist, raw, technical, monospace, minimal, stark

## Recommended color palette
- **Reference semantic palette:** Magazine/Blog
- `Primary` #18181B / `On Primary` #FFFFFF / `Secondary` #3F3F46 / `On Secondary` #FFFFFF / `Accent` #EC4899 / `On Accent` #FFFFFF / `Background` #FAFAFA / `Foreground` #09090B / `Card` #FFFFFF / `Card Foreground` #09090B / `Muted` #E8ECF0 / `Muted Foreground` #64748B / `Border` #E4E4E7 / `Destructive` #DC2626 / `On Destructive` #FFFFFF / `Ring` #18181B
- **Notes:** Editorial black + accent pink
- (The style's own Primary/Secondary colors above take precedence; use this set to fill semantic roles such as card, muted, border, ring, and destructive.)

## Visual & interaction guidelines
- Establish a clear visual hierarchy and consistent spacing, type scale, color, radius, shadow, and motion derived from the spec above.
- Provide clear interactive states: rest, hover, focus, pressed/selected, and disabled.
- Stay legible and well-composed from small mobile widths to large desktop widths; no horizontal overflow, no overlapping or clipped content.
- Maintain accessible color contrast and a clearly visible focus indicator.
- Respect a reduced-motion preference for non-essential animation.
- The interface must immediately communicate the "Brutalism" style through color, shape, type, texture, and motion. Be distinctive and opinionated, not generic.
