## Visual style: Interactive Cursor Design
- **Type:** General  ·  **Origin/Era:** 2025+ Interactive  ·  **Complexity:** Medium
- **Look & feel / keywords:** Custom cursor, cursor as tool, hover effects, cursor feedback, pointer transformation, cursor trail, magnetic cursor
- **Art direction:** Design with interactive cursor effects. Use: custom cursor, cursor morphing on hover, magnetic cursor pull, cursor trails, blend mode cursors, click feedback animations, cursor as interaction tool, pointer transformation.
- **Primary colors:** Brand-dependent, cursor accent color, high contrast for visibility
- **Secondary colors:** Trail colors, hover state colors, magnetic zone indicators, feedback colors
- **Effects & animation:** Cursor scale on hover, magnetic pull to elements, cursor morphing, trail effects, blend mode cursors, click feedback
- **Key design values:** --cursor-size: 20px, --cursor-hover-scale: 1.5, --magnetic-distance: 100px, --trail-length: 10, --trail-fade: 0.1, --blend-mode: difference
- **Best suited for:** Creative portfolios, interactive experiences, agency sites, product showcases, gaming, entertainment
- **Avoid for:** Mobile-first (no cursor), accessibility-critical, data-heavy dashboards, forms
- **Theme support:** Light ✓ Full · Dark ✓ Full  ·  **Mobile:** ✗ No cursor  ·  **Conversion:** ✓ High
- **Accessibility:** ⚠ Not for touch/SR  ·  **Performance:** ⚡ Good

## Recommended typography
- **Pairing:** Minimalist Portfolio (Sans + Sans)
- **Heading typeface:** Archivo
- **Body typeface:** Space Grotesk
- **Mood:** minimal, portfolio, designer, creative, clean, artistic

## Visual & interaction guidelines
- Establish a clear visual hierarchy and consistent spacing, type scale, color, radius, shadow, and motion derived from the spec above.
- Provide clear interactive states: rest, hover, focus, pressed/selected, and disabled.
- Stay legible and well-composed from small mobile widths to large desktop widths; no horizontal overflow, no overlapping or clipped content.
- Maintain accessible color contrast and a clearly visible focus indicator.
- Respect a reduced-motion preference for non-essential animation.
- The interface must immediately communicate the "Interactive Cursor Design" style through color, shape, type, texture, and motion. Be distinctive and opinionated, not generic.
